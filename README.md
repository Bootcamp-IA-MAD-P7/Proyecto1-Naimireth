# Proyecto1-Naimireth 

**TAXIGOTECH** es una solución de software orientada al sector del transporte, que digitaliza la lógica de un taxímetro tradicional mediante un backend en Python y una interfaz web amigable. El sistema calcula tarifas dinámicas en tiempo real, segmentando el estado del vehículo para ofrecer un desglose preciso del coste del trayecto.

## 📱 Módulos del Sistema y Vista Previa

### 1. Panel de Control del Taxímetro (Módulo Principal)
Centraliza la operación del viaje a través de una máquina de estados finitos (Disponible, En Viaje, Pausado, Finalizado). Incluye un **Feed Informativo** asíncrono que reporta el tráfico y eventos de tránsito.
 

### 2. Panel de Configuración de Tarifas
Permite la inyección de parametros para modificar las variables de cobro del algoritmo sin necesidad de reiniciar los servicios del servidor.
